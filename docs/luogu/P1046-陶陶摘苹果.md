## 解题思路

陶陶站在凳子上手能碰到的高度是 `身高 + 30`，所以只要苹果高度 **≤ 身高 + 30** 就能摘到。

```python
hight__apple = list(map(int, input().split()))   # 10 个苹果的高度
hight = int(input())                             # 陶陶的身高
hight2 = hight + 30                              # 加上凳子的高度
x = 0
for apple in hight__apple:
    if apple <= hight:
        x += 1
    elif apple <= hight2:
        x += 1
print(x)
```

## 可优化点

`if apple <= hight` 和 `elif apple <= hight2` 两个分支做的事完全一样，因为 `hight <= hight2`，
所以可以合并成一句：

```python
x += 1 if apple <= hight2 else 0
# 或者
x = sum(1 for apple in hight__apple if apple <= hight2)
```

当前写法虽然多了一层判断，但逻辑没问题，也能 AC。
