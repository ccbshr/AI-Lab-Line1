## 配图约定

粘贴图片用 **Ctrl+Alt+V**（Paste Image 扩展），图片自动落到**本笔记同级目录的 `assets/`**，插入形如：

```markdown
![描述性替代文本](assets/2026-10-17-17-00-02.png)
```

**两个硬规矩**：① 替代文本必须写"这张图在证明什么"，不要留时间戳；② 图片跟笔记放在一起，方便仓库迁移时不丢图。
