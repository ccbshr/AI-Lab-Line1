# Reading Notes

This file is mainly in English, so the word counter will treat each
English token as one word.

## Key points

- Context manager: `with open(...)` guarantees the file is closed.
- Always pass `encoding="utf-8"` to avoid the cp936 trap on Windows.
- Use `pathlib.Path` instead of string concatenation for paths.

## 中英混排测试

上下文管理器能保证文件被正确关闭，即使中间抛出异常也不会泄漏句柄。

Pathlib provides a much cleaner API than os.path, and it works on
Windows, macOS and Linux without any change.
