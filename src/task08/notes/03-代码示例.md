# 代码示例集合

## 文件读写

```python
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("你好\n")
```

## pathlib 遍历

```python
from pathlib import Path

for path in Path("notes").rglob("*.md"):
    print(path.name)
```

## 异常处理

```python
try:
    with open("missing.txt", "r", encoding="utf-8") as f:
        text = f.read()
except FileNotFoundError:
    print("文件不存在")
finally:
    print("清理完成")
```

## 说明

以上三段代码分别对应 Task 08 的四个学习点。
代码块里的英文会按单词计数，中文按字计数。
